# 🕹️ Tek Zanith - 3D Portfolio

A modern 3D portfolio website blending **Apple's minimalist aesthetic** with **retro arcade game elements**, built using **Three.js**, **GSAP**, and **Vite**.

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Features
- **3D Interactive Scene**: A sleek, metallic arcade cabinet in a cinematic starfield.
- **Dynamic HUD**: Retro-style UI displaying skills, experience, and achievements from my CV.
- **Parallax Effects**: Camera and 3D objects respond to mouse movement.
- **Apple-Inspired Design**: Glassmorphism, SF Pro typography, and clean layouts.
- **Score System**: Interactive sections that "score" points as you explore.

## 🛠️ Tech Stack
- **Three.js**: 3D Engine
- **GSAP**: High-performance animations
- **Vite**: Ultra-fast frontend tooling
- **CSS3**: Vanilla CSS with glassmorphism effects

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Tekzanith1/Zanith_3D_Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Zanith_3D_Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development
Start the local development server:
```bash
npm run dev
```

### Build
To create a production-ready build:
```bash
npm run build
```
